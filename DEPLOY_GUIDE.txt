FISAI MEETUP 2026 - GitHub Pages 배포 1분 요약

1) ZIP을 압축 해제한다.
2) github.com에서 New repository를 만든다. (Public / README 생성 권장)
3) 저장소의 Add file > Upload files에서 ZIP이 아닌, 압축 해제한 폴더 안의
   파일들과 docs 폴더를 드래그해서 올린다.
4) Commit changes를 클릭한다.
5) Settings > Pages > Deploy from a branch > main > /docs > Save
6) Pages에 표시된 실제 주소로 접속해 검색 및 이미지 표시를 테스트한다.
7) 그 실제 URL을 제출물 '배포_url.txt'에 한 줄로 저장한다.

저장소 루트에 반드시 docs/index.html 경로가 있어야 한다.
GitHub에 ZIP 파일만 올리면 웹사이트가 배포되지 않는다.
